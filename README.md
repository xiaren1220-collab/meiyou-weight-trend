# 体重趋势图交互 Demo

基于 Pixso「个人 / 页面 1 / 折线图」中「数据充足」「数据不充足」两个 375×812 画板。使用原生 HTML、CSS、JavaScript 与 SVG，无需安装依赖。

## 本地运行

在此目录运行 `python3 -m http.server 4180`，浏览器打开 `http://localhost:4180`。

## GitHub Pages

将 index.html、style.css、fidelity.css、app.js、curve.mjs、data.mjs 和 assets 文件夹上传到仓库根目录，在仓库 Settings → Pages 中选择部署分支和根目录。资源全部使用相对路径，可部署到项目子路径。

## 稀疏记录交互

- 点击或按住图表横向拖动，根据横坐标选择最近的真实记录。
- 两条记录之间以横坐标中点为边界，越过中点才切换。无需精确命中小圆点。
- 2025-09-01 到 2026-06-19 之间没有记录，长直线仅连接端点，选中结果只可能是现有真实记录。
- 松手保留最后一次选择。触摸使用 Pointer Events、指针捕获和 `touch-action: pan-y`，垂直操作保留页面滚动。
- 可用左右方向键选择记录，Home/End 跳到首条/末条。
- 灰卡实际宽度参与边界计算，左右距离白色卡片至少 12px。

## 数据与设计差异

全年数据为确定性 132 条模拟记录，均值四舍五入为 46.3，最大 48.3、最小 44.2、最新 44.6。稀疏数据为 22 条日期记录，默认显示稀疏模式。

按最新视觉还原要求，直接使用 Pixso 原始 SVG 贝塞尔路径，不再从取整数据重新拟合曲线。横坐标按原稿日期锚点分段映射，选中点在原始路径上取位置。日期仍属于真实记录，空档中不生成记录。数值记录为模拟数据，原稿曲线是示意几何，因此不作为精确测量图使用。对比值按固定基准 47.0 计算，初始显示 −2.4，替代原稿静态的 −4.4。

选中线 1px、曲线 2px；选中点外径 16px、4px 内描边；极值未选中点外径 8px、2px 内描边。图例使用用户提供的 36×36 三倍 PNG，以 12×12 显示。

字体绑定系统已安装的 PingFang SC Regular / Medium，禁用合成加粗。没有安装苹方的设备会使用系统字体回退，不能保证跨系统字体像素一致。

顶部时间范围、返回和所有记录入口保留原设计展示；本次交互范围是近一年图表与外部数据模式切换。

## 验证

`node verify.mjs` 检查记录数量、日期范围、均值、极值、空档中点选点、对比值和灰卡边界。浏览器已实际验证鼠标拖动、触摸拖动、切换模式、松手保留与无控制台异常。
